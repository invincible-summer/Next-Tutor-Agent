# ADR-0020: 独立的本地电路实验室

- 状态：accepted
- 日期：2026-10-08

## Context

项目需要增加与化学实验室并列的电学实验室。电路实验强调自由接线、仪器负载、连续计算和示波器反馈；化学实验室的服务端会话、内容包、命令回放和预测对账并不适合这种连续桌面交互。用户同时要求不接入 AI、不做对话，并允许教学级理想化。

## Decision

新增一个独立的浏览器端电路领域：

- 电路模型和求解器只实现一次，位于 `packages/domain/src/electrical-lab/`，由 Web 工作台直接调用。
- 直流与瞬态采用确定性的 MNA/Backward Euler 教学级求解；仪器以有限输入阻抗参与计算。
- 实验状态使用按用户隔离的 `localStorage` 保存，提供版本化 JSON 导入导出；不新增后端 API、数据库或 contracts。
- `/tools/lab/electronics` 使用独立沉浸式壳，隐藏全局导航和站内助手，仅保留一个可收起器材架；不使用化学实验室的组件和同步实现。

## Consequences

电路编辑、仪表反馈和示波器可以离线即时运行，依赖少且容易分享实验快照。实验不会跨设备同步，也不会写入学习记录；以后若需要云端保存，应新增独立 ADR 和 API，不把本地文档迁入化学实验室会话体系。
