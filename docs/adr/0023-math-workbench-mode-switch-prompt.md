# ADR-0023: 作图器模式切换保存提示与右栏按模式分域

- 状态：accepted
- 日期：2026-10-10

## Context

ADR-0022 让三个绘图模式各自持有独立 bundle（document/history/baseline/dirty），模式切换因此被设计为"零成本直达"——不弹确认、不进撤销、不销毁数据。实际使用与用户反馈暴露三类问题：

1. **切换提示缺失**：用户在模式 A 有未保存更改时切到模式 B，界面上没有任何"先保存"的提醒；虽然 bundle 仍在内存中，但刷新/关闭浏览器后未保存内容丢失，且崩溃恢复草稿容易被误以为已经处理。
2. **右栏内容跨模式泄漏**：四个页签（函数/对象/属性/计算）在所有模式中写死显示——平面几何里出现无意义的函数页签，函数模式里出现无用的属性页签；计算面板与函数列表互相挤占布局、状态易丢。
3. **平面几何构造不可用**：构造工具从不复用已有点（每次点击都新建重复点）、线段创建产生 3 条撤销记录、无预览无取消；对象/属性面板几乎只读，无法承担属性编辑职责。

## Decision

1. **模式切换经 dirty 检查（本 ADR 的核心修订）**：`FileIntent` 闭集新增 `{ kind: "switch-mode"; mode }`。模式面板/`Alt+1/2/3` 都经由 `requestDestructiveTransition`：当前模式 dirty 时弹三选一（保存并切换 / 直接切换 / 取消）。**切换本身仍不销毁数据**——"直接切换"不清除该模式的 bundle，也不清除其崩溃恢复草稿（与 `leave`/`new` 等真正破坏性意图的语义区分）；弹窗文案使用"直接切换"而非"放弃更改"。ADR-0022 的"切换零成本"语义在数据层面不变，仅在交互层面增加保存提醒。
2. **右栏按模式分域**：`functions2d = [函数, 数学工具]`；`geometry2d = [对象, 属性]`（均为升级版）；`functions3d = [函数]`（单页签显示为标题）。折叠胶囊标签显示当前页签名；上一模式的页签残留回落到新模式首页签。
3. **数学工具面板独立成组件**（`AnalysisPanel`）：求值/导数/定积分/解方程各有专属结构化结果卡（KaTeX 排版、根列表含单根/重根徽章与方法标注、积分收敛元信息），可从当前文档的显式函数曲线直接选择输入源；面板保持挂载（隐藏）以在页签切换间保留状态。
4. **平面几何构造语义**（`Stage2D`）：构造点击先命中已有点（磁性吸附容差 14px 屏距）则复用其 id，否则网格吸附新建；点工具点击已有点改为选中。新点与图形合并为单个 `batch` 命令——一次撤销。支持点击-点击与拖拽两种手势，构造中有虚线橡皮筋预览与悬停光环；`Esc` 取消构造（再次按取消选择），`Delete`/`Backspace` 删除选中对象。零长度/同点重复点击被忽略。构造状态随工具与文档派生失效（`activePending`），不依赖 effect 重置。
5. **对象/属性面板升级**（`GeometryInspector`）：对象列表提供类型徽章、行内标签编辑与解析摘要（坐标/线段长/半径）；属性面板启用标签编辑、自由点坐标可直接键入、派生构造只读展示输入、样式/线宽/可见/锁定/级联删除。

## Consequences

- 模式切换在 dirty 时多一步确认；干净状态下仍是零点击直达。e2e 需要在切换前处理弹窗（或先保存）。
- "直接切换"后旧模式仍保持 dirty，状态栏与未保存指示继续如实反映；崩溃恢复草稿保留，关页前仍会触发原生 `beforeunload` 提示。
- 数学工具仅在 `functions2d` 提供页签（2D 单变量分析）；3D 曲面的求导/积分如需支持应另立设计。
- ADR-0022 的其余决定（三模式、独立画布、存档 v2、视图命令不进撤销）不变；本 ADR 修订其"切换不弹确认"一条。
