# ADR-0019: 确定性双引擎模拟实验台（Python 权威 + TS 镜像）

- 状态：accepted
- 日期：2026-10-08
- 关联：ADR-0001（源码仓库，内容包为项目自研合成内容入库）、ADR-0002（会话数据落运行时数据根）、ADR-0005（synthetic 内容原则）。

## Context

工具助手要新增「模拟实验室」：学生拖放器材、倾倒、加热、测量，即时看到液体、沉淀、气泡与读数变化。三项硬需求互相拉扯：

1. **交互即时性**：拖拽与操作需要毫秒级反馈，弱网/离线也要可继续探索；
2. **服务端权威**：会话须可回放、可分叉、可生成结果卡，且预测题答案不能随包下发到客户端；
3. **内容可扩展**：新增实验应只改内容包，不改引擎代码。

候选方案：

- **纯服务端往返**（每命令一次请求，画面完全由服务端投影）：实现最薄，但每次拖动/倾倒都要等 RTT，弱网体验不可接受，且离线完全不可用。
- **纯客户端模拟**：反馈即时，但服务端无权威状态，回放/分叉/结果卡全部落空，预测题答案必须下发，无法防作弊。
- **CRDT/操作变换类协同**：为多端并发设计，单用户实验台属于过度工程，且无法给出"唯一权威状态"。

约束：命令语义必须确定（同一初始状态 + 同一命令序列 ⇒ 同一状态）；内容包更新不得破坏进行中的会话；前端 Web Worker 能力可用。

## Decision

**确定性双引擎**：Python 引擎（`app/chem_lab/engine/`）为唯一权威，TypeScript 镜像（`packages/domain/src/chem-lab/`）与其同构实现同一 command/event/render union；两个引擎消费**同一份**内容包 JSON。

- 内容包由 `manifest.json` 的逐文件 sha256 锚定；`pack_hash` 绑定会话，进行中的会话不随内容更新漂移。
- 客户端在 Web Worker 中跑 TS 镜像做本地预测；命令经有序队列逐条 POST，`base_revision = tip + i`。该基址确定成立依赖一条公开契约：**任何命令（含被拒绝者）revision 均 +1**。
- ACK 携带 `revision + state_hash`：与本地预测相等即证明双引擎一致、免回拉；不等标记 diverged 整快照 resync；409 丢弃预测重对齐；断网进入 offline_preview 降级、恢复后重放队列。
- `engine-pack` 端点把运行时包原样发给 TS 镜像，但剥离预测选项的 `correct` 标记；服务端逐条重跑命令，客户端预测永远只是预测。
- 双引擎一致性由 CI 强制：内容包回放向量同时被 Python 与 TS 测试执行，state_hash、事件类型、关键读数必须一致。
- AI 能力只经 `providers.py` 的 Protocol 预留（场景/指导/起草），默认实现无模型调用；AI 永不写 LabState、永不执行命令。

## Consequences

- 即时反馈、离线降级、服务端回放/分叉/结果卡、预测题防作弊同时成立。
- 新增实验（已有原语覆盖）零引擎改动：内容包 + 回放向量 + manifest 刷新即可。
- 成本：新操作/新规则原语必须双实现（Python + TS）并配双回放向量；`reducer` 的 revision 语义成为冻结契约，违反即破坏客户端队列基址。
- TS/Python 两处实现对同一 bug 可能双倍暴露；缓解方式是回放向量覆盖正确路径、换序、错误操作、边界量与重置，且 ACK hash 对账能立刻发现漂移。
- 移动端首期不承载实验台；若后续接入，复用 `packages/domain` 镜像与同一同步协议即可。
