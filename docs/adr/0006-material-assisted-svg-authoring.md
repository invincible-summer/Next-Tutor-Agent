# ADR-0006：V3 使用素材参考进行自由 SVG 创作

- 状态：accepted
- 日期：2026-10-04

## Context

受限素材装配可确定性检查参数和关系，但难以表达库中没有的对象或新的组合。自由绘图需要素材参考，也需要守住必要读图条件、答案隔离及实际成图的发布边界。

## Decision

- 保留 V1/V2 及既有默认；新增 V3，普通出题、聊天工具及 CAT 共用版本选择，失败和重试保持所选版本。
- V3 让模型以自然语言提出素材需求，由项目模糊检索并提供有限、完整、属主可见的 SVG。模型自行取舍、加工、组合及绘制缺失元素，不要求 V2 参数、端口或实体关系合同，不按具体场景分支。
- 用轻量绘图合同绑定公开题面和绘图输入。必要读图题可将数值交给创作模型驱动几何，同时限制其文本披露；答案、解析、量规及教材证据只交给独立审核者。冻结 CAT 仅使用公开支持的条件。
- V2/V3 通过安全规范化、实际 Chromium PNG 和一次合并题图审核后冻结。保持公开图片 schema 3 兼容，版本分别使用私有来源合同；历史冻结 V2 审核门仍兼容。
- 配图拥有独立的调用、时间和修复预算，批量并发有上限；公开题目注册前完成必要材料和不可变 artifact。

## Consequences

- 素材覆盖不足不再直接限制 V3 的绘图表达，模型的空间和数值绘图能力成为质量变量。
- SVG 安全和机器边界检查不能证明科学正确；实际 PNG 审核仍是发布前必要条件，有限修复失败时明确返回失败。
- 实测边界、原稿、素材版本及哈希、绘图合同、审核证据保持私有可追溯；学生端继续使用原有规范化图片协议。
- 验收必须覆盖素材加工、自绘、跨学科场景、必要读图和正式注册，不能以少量成功样本推定零失败。
