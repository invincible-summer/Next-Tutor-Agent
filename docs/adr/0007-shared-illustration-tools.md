# ADR-0007：配图作为工具助手的独立能力

- 状态：accepted
- 日期：2026-10-04

## Context

V1–V3 原先主要服务出题，需求、任务身份和审核规则绑定题目。课件及辅导也需要这些绘图能力，用户还需要通过聊天选择素材并持续修改图片。直接复用题目任务端点会把通用配图带入题目注册、答案审核和学习评价账本。

## Decision

- 「工具助手」作为与测评中心、资料中心平行的产品栏目，「情景配图」为第一个独立工具。共享绘图能力归 `app/illustration/`，测评是其业务消费者，测评配图 API 继续保持兼容。
- 共享 V1 绘图、V2 受限装配、V3 素材参考创作的底层能力。情景输入和审核显式声明任务用途，不创建用于占位的题目，不写学习证据；测评保留答案隔离、必要读图和题目冻结发布门。
- 情景配图按会话保存轮次和成功图片版本，用户选择的基础版本及此前需求进入后续创作。每次成功生成新版本，历史成果不可变；同会话在途任务互斥，提交幂等，基础版本受服务端校验。
- V2/V3 手选素材提交 ID 与版本，服务端从属主可见范围读取。手选时构图参考限定为选定集合；未手选时由模型声明需求，项目检索候选。V2 保持能力/视角约束，V3 允许改绘、组合及补画。
- 情景会话及任务复用 `illustrations/<owner>/` 运行根，全部 JSON 原子写。账户删除同时失效运行 epoch 并取消任务，原有题图数据无需迁移。

## Consequences

- 工具助手形成可独立演进的产品入口，课件和辅导后续可消费共享入口而无需经过出题流程。
- 情景配图与题图使用不同业务审核上下文，共享安全规范化、素材和实际渲染能力；不能用通用审核替代测评联合审图。
- 改动对象、数量或场景属于新的创作版本；不能绕过原合同以审核修复补丁悄悄更改已经冻结的题目事实。
- 回归同时覆盖独立配图和测评链路，真实模型质量与 fake-provider 协议回归分别验证。
