# ADR-0024: 化学自由探索 Three.js 实验台

- 状态：accepted
- 日期：2026-10-10
- 取代：[ADR-0019](./0019-deterministic-dual-engine-lab.md) 的化学实验台当前实现

## Context

旧实验台把化学场景建模成服务端会话、步骤、指导、评估和历史回放。它不适合一个可以自由拆装、观察现象和反复试玩的模拟台面：每次拖动都要穿过命令同步，器材几何、端口命中和 DOM 热区也容易产生多个事实源。

## Decision

当前 `/tools/lab/chemistry` 使用一个纯 TypeScript 文档内核和一个 Three.js 场景：

- `EquipmentSpec` 是尺寸、端口、锚点、控件和气泡能力的唯一来源；模型、软管、命中壳和 UI 从它派生。
- `LabDocument` 只保存器材姿态、挂载关系、连接、视觉内容和控件状态。动作在浏览器本地原子应用，场景操作不请求后端。
- `StageDefinition` 只提供主题、器材库存、起始场景、AUTO 装配快照、镜头和视觉 cue。没有目标、步骤、答案、分数、完成判据或安全锁。
- `SceneSync` 是文档到 Three.js 的唯一同步边界；`InteractionController` 是唯一指针状态机；`ObjectPopover` 是唯一器材操作入口。
- 后方器材架提供可点击的真实缩小模型，取用动作只产生一个 `add` 文档动作。局部气泡负责倒液、点火、阀门、泵和脉冲等动作。
- `Effects` 只读文档并播放短暂视觉现象。它不写文档、不改变历史，也不宣称真实化学安全或计量结果。
- 保存使用浏览器本地有界 JSON，支持自由探索的延续，不恢复旧会话的步骤或评估语义。

## Consequences

场景动作即时且可离线；新器材只需要注册 domain spec、程序化模型和可选 stage 模板。旧 Python/TS 双引擎、内容包和会话 API 已从仓库移除，架构文档必须保持当前 3D 文档内核为唯一现行描述。
