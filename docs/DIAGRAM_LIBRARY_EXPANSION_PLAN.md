## 绘图与配图合同

新增渲染代码集中在登记模块 `curriculum_expansion.py`，显式登记到对应现有学科 family。每个ID都有独立SVG、material.json及简洁usage_guide.json；共享原语不等于共享整段系统提示。主提示不增加具体材料约束。

默认480×320纸面；所有路径、箭头、文字原创，双风格可辨。仪器完整结构不拆成没有真实端口的假组件。静态内部导线/管道只属于整体图，不能给出任意外接端口。固定模型只暴露static_illustration；数值控制只有确实驱动画面时才登记，并参与事实绑定，不能让图件默认数字冒充题目条件。

参数采用有限数值/枚举：闭端气柱mode=1..3对应奇次模态、半衰期halflives=1..5、色谱两个归一化保留位置0..1、单位圆角度0..360、割线步长0.2..2、昼长纬度±60与太阳赤纬±23.44、谱线位移0..60像素、条件概率两个0..1分支概率。像素位移只能用于非定量示意；物理量与数据控制保留真实单位。其余没有参数的科学示意只匹配题文明示构造，不能假称精密测量、实验验证或通用方程求解能力。

每项简短说明只描述该图确实包含的对象、箭头/颜色/固定标注以及用途边界。固有公式、箭头方向和阶段名称必须在题文中已知，或作为允许的读图材料；如它会直接泄露当前待求结论，拒绝使用。不同水合层是截面符号，不把绘制水分子个数声明为真实配位数。概率、轨迹、化学图不得引入不受控数据。

## 科学核对

仅参考事实，原创画线，不引入外部图形或教材内容：

- 水分子键角：[OpenStax Chemistry](https://openstax.org/books/chemistry/pages/8-2-hybrid-atomic-orbitals)。
- 水合时氧端朝向阳离子：[OpenStax Biology 2e](https://openstax.org/books/biology-2e/pages/2-2-water)。
- 自流井并非所有承压井都自动溢流，须水头高于地面：[USGS](https://www.usgs.gov/water-science-school/science/artesian-water-and-artesian-wells)。
- 上升流图表达离岸表层输运及深层补偿，不混淆沿岸风与离岸流：[NOAA](https://oceanservice.noaa.gov/facts/upwelling.html)。

其余模态、环流、半保留复制等疑难关系在实现和审阅时继续对照官方教育资料。参考URL和用途写入对应素材来源记录，不复制参考图片。

## 顺序执行与出口

1. 实现物理10项；再化学8项与水分子；再地理8项；再其他14项与叶绿体。参数单位、锚点、能力均通过全库适配器，未经审核不参与检索。
2. 构建目录后重新渲染全部1119项彩色/黑白及新增参数端点。默认图逐一比较上一轮实际SVG；绘图完全一致者可保留已有人工/智能体审阅证据。新图和变化图全部查看PNG，两种风格逐一复核，疑点放大、修正后再渲染。不能仅刷新hash凑审核。
3. 为40个新增ID写独立简洁指南，生成1130个素材包（1119+10配方+1创作基底），检查可重现性、源码审核、参数边界、非法输入、无无关提示泄漏。
4. 真实调用当前模型跨新增物理、化学、地理、生物、天文、数学、统计和工程情景出题，改变参数再跑代表情景。逐张审阅实际PNG，两道模型审核门均须通过。保留拒绝和修正证据，不放宽审核或增大调用预算凑结果。
5. 跑相关后端回归、目录/包构建检查、卫生及diff检查；浏览器查看新增公有素材与两种风格，最后更新清单、扩充验收和现状文档。已有前端编辑器检查/构建已通过，若再改产品代码则重新执行前端检查与构建。
