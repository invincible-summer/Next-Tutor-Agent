## 素材与接口

公有内置目录为 **1,119 项素材、17 学科、34 素材族**，另有 10 个装配配方和 1 个设计基底，合计 **1,130 个独立素材包**。清单见 [素材参考](../reference/diagram-assets.md)。全部素材包携带统一 `material.json.interface@1.0.0`，各自保存 SVG、接口与使用说明；本轮 `build_packages.py --check` 通过。

V1 的构图提示、绘图、预览与检查使用同一实际 drawing/parts/ports/regions；包含、支撑、悬挂与导线避让使用通用协议，不按素材 ID 添加适配。V2 使用已检索素材的完整 SVG 和接口，参数、事实、关系与标注受编译校验约束。个人素材的版本、所有权与公开素材权限边界保持不变。

## 回归与使用条件

V2/V3 合同、实际 PNG、修复与反馈隔离、五题独立预算、真实 JWT/ASGI 任务、重试、正式注册/量规冻结的聚焦回归通过。前端 `pnpm check`、生产构建、浏览器 V1/V2/V3 模式及历史恢复回归 8/8、960px 桌面补测 1/1 通过，人工查看浅色/深色界面。文档检查、仓库卫生及 diff 检查通过；后端全量 **2,882 项通过**；之后新增审核观测值、目标、元数据及外侧排版修复由最后两组 **111 项聚焦回归**覆盖，全部通过。

使用真实 PNG 审核需要模型图片输入能力、`LLM_SUPPORTS_IMAGES=1` 及 Playwright Chromium。CAT 使用账户默认 V1/V2/V3 或按次覆盖，账户显式选择 V3 时所有普通出题入口也使用 V3，旧默认保持兼容。V2/V3 审核门为 active，历史 V2 冻结双审结果仍可读。

安全规范化和机器检查不能证明自由 SVG 的科学正确性，模型审核也可能误判；`observed_values` 仍来自模型，不能替代任意定量图的确定性数值证明或人工科学验收。当前模型在密集标定、曲线和复杂结构上仍可能达到修复预算而失败；系统明确失败并提供同版本重试，不宣称全库组合零失败。必要图未通过不能注册为可作答任务。真实模型验收覆盖生成/审核/冻结；HTTP 权限与并发生命周期由聚焦测试覆盖。
