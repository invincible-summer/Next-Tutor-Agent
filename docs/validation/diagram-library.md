## 素材与接口

公有内置目录为 **1,119 项素材、17 学科、34 素材族**，另有 10 个装配配方和 1 个设计基底，合计 **1,130 个独立素材包**。清单见 [素材参考](../reference/diagram-assets.md)。全部素材包携带统一 `material.json.interface@1.0.0`，各自保存 SVG、接口与使用说明；本轮 `build_packages.py --check` 通过。

V1 的构图提示、绘图、预览与检查使用同一实际 drawing/parts/ports/regions；包含、支撑、悬挂与导线避让使用通用协议，不按素材 ID 添加适配。V2 使用已检索素材的完整 SVG 和接口，参数、事实、关系与标注受编译校验约束。个人素材的版本、所有权与公开素材权限边界保持不变。

## 回归与使用条件

测评草稿拒绝与生命周期、统一素材接口、布局/导线、V1 补图、V2 合同/审核、任务并发/旧失败恢复的聚焦测试通过；前端 `pnpm check` 通过；素材包生成检查、文档检查及 `git diff --check` 通过。本轮没有重跑后端全量、生产构建或完整浏览器 E2E。

使用真实 PNG 审核需要模型图片输入能力、`LLM_SUPPORTS_IMAGES=1` 及 Playwright Chromium。CAT 使用账户默认的 V1/V2，可在出题中心覆盖；普通出题仍受 `QUIZ_ILLUSTRATION_PIPELINE` 配置约束。缺真实能力时明确失败，不把可解析 SVG 当审核成功。

这些样本覆盖自足文字题的补充图，不能替代必要读图题在注册前的命题验收，也不表示任意素材组合都零失败。V1 数量来源仍按单位与读数/量程角色进行词法校验，尚不具备 V2 完整实体事实绑定；关闭账户 V1 审核时只执行确定性检查。真实模型验收直接调用冻结题图管线，HTTP 权限与持久任务生命周期另由聚焦测试覆盖。
