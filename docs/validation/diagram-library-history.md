# V1/V2 配图版本回顾与优化建议（2026-10-04）

本文记录本轮版本演进、失败证据和后续优化建议，不是当前能力声明或实施承诺。当前可用行为见 [题图架构](../architecture/diagrams-illustration.md)，当前验收基线见 [测评配图验收](diagram-library.md)。

## 本轮交付边界

本轮先交付 V1/V2 都可完成测评补图的版本。V1 接受不影响作答的轻微呈现瑕疵；数量、状态、单位、物理关系、导线结构和泄题仍属于失败。采用通用素材接口与约束求解，不通过特定素材 ID 或某道题的答案添加适配分支。

| --- | --- |
| V1 | renderer 1.2.0；需求 1.6.0、构图 1.9.0、PNG 语义审查 1.7.0 |
| V2 | renderer 2.4.0；需求、构图、视觉审查、联合审查 2.20.0 |

## 失败调查与取舍

早期 V1 的“ready”结果不能直接证明科学正确：仅文字审核曾漏过测量部件没有浸入介质、读数借用无关数值、导线可见重合造成短路等问题。后续启用实际 PNG 审核、匹配数量角色与单位，并检查可见导线网络。此前记录的 V1 10/10 只能视为旧实现的状态返回样本，不能计入本轮最终通过数。

真实模型还暴露了素材接口不一致：V1 绘制原生图，却使用装配视图的区域检查支撑关系。现统一 drawing/parts/ports/regions，按真实接触端口检查，不将 viewBox 边缘或 center 定位点作为物理接触证明。支撑链先处理依赖目标，容器分层不依模型节点顺序，循环关系拒绝。导线从真实端子外侧逃逸，避让敏感区域和其他端子网络，最终再核对网络是否被交叉或重合改变。

V2 原测评入口只有空冻结材料合同，需求阶段原先无法补出必要材料定义。修复允许第一次从公开文字提取材料与需求，后续仍冻结实体、事实和题目身份；协议错误可在同一请求中校正。上下关系、配方子部件映射和标注点位由通用协议验证，不能任意猜测实体或改变作答依据。

V1 的一轮后期样本在科学条件正确时仍因缺少问句操作目标的附加图示失败。该问题通过通用的“已给事实与求解目标分离”及有限呈现 warnings 收敛：可省略不必要的操作示意，不能把真正的科学条件缺失包装成 warning。纯 warning 不要求用户重试。

任务超时也不只发生在模型：Next.js 内置反向代理默认超时会先截断服务端尚在运行的 V1 请求。现代理、浏览器和服务端预算衔接，并通过 single-flight、活动任务恢复与终态检查避免重复调用；这并不能消除外部 provider 的超时或网络故障。

## 详细优化建议

这些建议是本轮回顾形成的后续方向，尚未全部实现，不属于当前版本验收承诺。

1. **扩充通用验收矩阵。** 从固定例题扩展到单素材、完整构图、多个独立部件、私有上传素材、读数、数据图、包含、支撑、悬挂与连接；变化节点顺序、数量、单位、视角和参数边界。除成功样本外，加入无关数字、选项干扰、否定条件、未知端口、循环与不可满足关系。必要读图命题与冻结文字补图分别统计，不能混用通过率。
2. **减少首次声明方差。** 继续由已检索素材的接口提供参数角色、合法端口、真实区域与示意许可，避免把所有素材的规则塞入主提示词。对不支持的控制在声明阶段给出有限反馈，减少构图后才发现缺少读数、数据或状态授权的浪费。
3. **加强 V1 的事实归属。** 当前 V1 数量来源主要依单位与读数/量程角色进行词法校验，仍弱于 V2 的实体事实绑定。后续可逐步引入明确的实体、参数和公开来源引用，防止同单位的多个对象互借数值；不得让选项或私有答案授权绘图条件。
4. **补全通用物理接口。** 对可组合素材明确接触面、端口用途、动态区域和真实笔画边界。没有登记接触能力的素材应明确限制，不依相似外形猜测。旋转、多个约束和不同导线网络的不可布线情形应提供闭合的结构反馈，避免重复提交同一不可行草稿。
5. **把呈现质量与科学正确性分开评估。** V1 保持有限 warning 许可，V2 保留实际 PNG 双审；分别记录误拒绝、漏判和修复效果。审核失败只向构图器回传允许的结构字段与问题码，保留私有判分隔离。重复修复没有改变相关结构时，可提前识别并调整声明或终止，减少无效调用。
6. **持续测量用户请求的稳定性。** 按链路记录首次请求成功率、内部校正次数、阶段耗时、超时和模型能力不足，不将内部多次调用称为单次模型成功。增加真实 HTTP 的断连恢复、代理超时、并发和旧失败迁移验收，并继续确保隔离临时存储、无生产账户数据或密钥入库。

修复包括需求材料提取、真实能力词表、符号等价表达、科学事实与示意控制分离、点位标记、完整修复预算、旧失败任务版本迁移及前端任务恢复。纯呈现 warning 可通过；科学错误、泄题、缺必需条件及无图片输入能力的发布门保留。原题干、答案、量规和 revision 均保持冻结。

- 出题经过确定性编译、Chromium 实测与实际 PNG、独立视觉审核和图文联合审核；必要配图未通过时不交付该题。
