## 改了什么

### 1. 迁移 CLI（§16.2 合同）

新增 `scripts/migrate_learning_evidence.py`（本地 CLI，服务启动零隐式扫描、零 LLM 调用）：

| 能力 | 实现 |
|---|---|
| `--dry-run` | 全计划计算零写入；打印计数/分类（不打印题干/答案等私有正文） |
| `--apply --manifest <path>` | 备份→journal 追加→文件改写→manifest（输入 hash/条目数/映射数/不可恢复分类/输出 hash/清理清单/错误/阶段标记） |
| `--verify --manifest` | journal/改写文件 hash + source 计数 + （cleanup 后）旧文件缺位核对 |
| `--cleanup-legacy --manifest` | 仅删 manifest 精确路径（`students/<sid>.{learning_records,quiz_recent}.json`/`.events.jsonl`/`.assessment.json`），拒绝任何不安全路径；要求先过 verify |
| `--rollback --manifest` | 仅离线演练：按备份原路径还原 + 删除迁移新增 journal；打印新写入先导出警告（§16.6.6） |

- manifest 与备份都在仓库之外（`~/edu_agent_migration_backups/`，脚本强制校验路径不在 repo 内）。
- 迁移语义（§16.1/16.3）：只迁原始材料——题目注册 TaskSnapshot（rubric 由旧记录
  correct_answer 确定性导出、迁移时刻冻结，`frozen_at` 为真值不谎称旧时冻结）、作答注册
  SourceReceipt（真实 `observed_at`、session→workspace 归属从聊天档案验证，不确定则
  unassigned、`provenance=migration|demo_fixture`）；MC 确定性判分提交 TaskResult 并显式
  取消语义作业（不留假 pending）；开放题保持待回填（§16.4 backfill 是显式后续动作）。
  events 的 concept_taught/self_report 不迁为证据；quiz_recent 为截断镜像（stem 160/答案
  200 截断、归一化前缀对账）不重复迁移；旧槽 assessment.json 可恢复题目/作答迁移、旧算法
  实例状态不迁移。

**演练（student_default，运行目录测试账号）**：apply(16 tx/10 sources/5 MC 判分) →
verify OK → cleanup(4 文件) → rollback 还原 11 项+删 journal → re-apply → verify →
cleanup → 再 dry-run 幂等（txs=0）。全链路通过后才动 demo。
