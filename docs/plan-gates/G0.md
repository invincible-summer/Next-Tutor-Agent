## 关键协议决策（G0 出口条件：无关键协议 TBD）

| 议题 | 决策 |
|---|---|
| 复核语义 | review 引用 `interpretation_id`；P5 输出 `ReviewDecisionOutput`；revise 的替代解释在同一 `source_revision` 上替换（§12.4） |
| 重做语义 | 重练 = 新 SourceReceipt/新 attempt（新观察）；`source_revised`（如改转写）才 bump `source_revision`，同一观察身份（A16） |
| null 判分 | `TaskResult.task_score/verdict` 可空；`verdict=null` 不进正误统计/CAT 步进/SRS 成功分支；必需 criterion 未观察 ⇒ `grading_status=indeterminate`（A04） |
| 题目身份 | 一律 `question_id + question_revision + attempt_id`；答案按完整指纹（sha256 canonical）判重，题干/答案前缀不作为身份（A05） |
| 状态 | `ConceptState` 五类不映射数值；运行态 `EvaluationStatus` 分离；`ScopeStatus` 表来源范围 |
| 存储形态 | 单 journal：`students/<sid>.learning_evidence.jsonl`（唯一事实）+ `…_index.json` + `learner_views.json`（可重建投影）（§6.3） |
| 时间 | UTC ISO-8601（`…Z` 秒级）；逻辑顺序 = journal `seq` / `observed_at` |
| checksum | sha256 over canonical JSON（sort_keys, ensure_ascii=False, 紧凑分隔符），排除 `checksum` 字段 |

## 迁移 manifest 契约（G6 实施脚本 `scripts/migrate_learning_evidence.py`）

```json
{
  "manifest_version": 1,
  "created_at": "…Z",
  "baseline_commit": "889bfe1…",
  "schema_version": 1,
  "stage": "dry-run | apply | verify | cleanup | rollback",
  "users": [{
    "student_id": "usr_…",
    "inputs": [{"path": "students/<sid>.learning_records.json",
                "sha256": "…", "entries": 123}],
    "mappings": {"records_registered": 100, "sources_registered": 80,
                 "tasks_registered": 60, "skipped": 20},
    "unrecoverable": [{"kind": "legacy_truncated", "count": 3,
                       "record_ids": ["lr_…"]}],
    "output": {"journal_sha256": "…", "transactions": 42},
    "cleanup_paths": ["students/<sid>.learning_records.json",
                      "students/<sid>.events.jsonl"],
    "errors": []
  }],
  "phases_completed": {"dry_run": true, "apply": false,
                       "verify": false, "cleanup": false}
}
```

规则（§16.2）：`--dry-run` 零写入；`--apply --manifest` 幂等（重复执行
同 manifest 不产生第二份观察）；`--verify` 比对 journal 重放与 manifest
计数；`--cleanup-legacy` 只按 manifest 精确路径清理；`--rollback` 仅演练。
不迁移任何旧模型派生能力结论（§16.1）；`p_known`/`understood` 等旧值不
转换为新状态。

## 唯一来源与验证方式

- 新评价写入唯一入口 = `evaluation/service.py` → `evaluation/store.py`
  （journal append）。G1 起以调用图断言闭合（invariant 扫描）。
- 身份：`student_id` 仅来自 `resolve_student_id`；`ConceptRef.key` 为
  sha256(namespace,textbook,concept,revision)——测试断言跨 namespace
  不相等（`test_learner_schema.py::test_concept_ref_key_stable_and_scoped`）。
- 引用：`EvidenceSpan.quote == canonical_text[start:end]` 由 validator
  在提交前强制（G1 `test_semantic_validator`）。

## 已知限制

- 本关只落 schema 与映射契约；调用链收口、旧实现删除在 G1–G6。
- ContextPack 内层分层（prior/related/materials）以受控 dict 承载——
  它们是 LLM user message 的 JSON 序列化边界（§8.1），非长期协议对象；
  其 allowlist 短引用映射（`allowlist` 字段）是强类型。
