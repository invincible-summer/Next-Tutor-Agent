## 唯一来源是否闭合

- dialogue 受理唯一入口 = `dialogue.register_dialogue_source`（chat hook 与测试同路径）；同 message_id 幂等。
- 复核/撤销/综合写路径全部经 journal ops（review_requested/resolved、interpretation_revoked、synthesis_committed）；GET 全部零 LLM（route 测试断言 runner.calls==0）。

## 身份/范围和引用如何验证

- 身份：evidence 详情所有权双检（游客读他人 source 404）。
- 范围：会话移动后历史仍归观察时工作区（`test_evaluation_lifecycle::test_history_stays...`）；scope 变化越界概念退出 + 任务取消。
- 引用：prior 按概念归属过滤；物化判断 claim 携带 obs 引用；invalidate 按 source/judgment 依赖传播。
