# Electrical Lab（独立电路实验台）

电路实验室是工具栏目下与化学实验室并列的浏览器端模拟实验台。它不接入 AI、聊天、学习证据或后端会话；电路文档、求解、仪器读数和示波器数据都在浏览器内确定性运行。

## 入口与边界

- `/tools/lab/electronics` 直接进入电路工作台，不经过实验选择页。
- `/tools` 提供独立的“电路实验室”入口；既有 `/tools/lab` 和 `/tools/lab/chemistry` 保持化学实验室行为。
- 电路路由由 `AppShell` 以沉浸式页面渲染，隐藏全局导航、顶栏和站内助手；工作台以中央电路桌为主，左侧器材架和右侧仪器测量栏都可收起，测量栏默认关闭。
- 页面不调用 `apiFetch`、`@next-tutor/api-client`、`@next-tutor/contracts` 或 AI 接口，也不写学生模型、知识图谱、聊天记录或评价账本。

## 代码归属

- 纯领域模型位于 `packages/domain/src/electrical-lab/`：文档模型、单位解析、拓扑归一化、Modified Nodal Analysis、Backward Euler 瞬态求解、器件模型、仪表投影和精选实验。
- 前端位于 `apps/web/src/components/pages/tools/electrical-lab/`：沉浸式场景、SVG 电路桌、仪器面板、示波器、器材架、拖线交互、本地保存和 JSON 交换。
- 所有器材图形由 SVG/CSS 原创绘制；不复用化学实验室的场景、内容包、命令队列、服务端会话或双引擎同步代码。

## 电路模型

状态分为两层：`ElectricalLabDocument` 只保存用户电路、位置、导线、仪器设置和视图；`SimulationFrame` 保存求解后的节点电压、支路电流、功率、仪器读数、示波器样本和诊断。移动器材不会改变连接关系，导线交叉也不会自动连接，只有端子或显式节点形成网络。

首版器件包括地、电压源、电流源、电阻、电导、电位器、开关、电容、电感、灯泡、二极管、LED、NPN/PNP 三极管。求解器采用 SI 双精度，直流使用 MNA，瞬态使用固定步长 Backward Euler。二极管、灯泡和三极管使用有限范围的教学级非线性模型；矩阵奇异、浮空、过流和不收敛会返回诊断状态，不把错误读数伪装成成功。

## 仪器

- 直流电源：0–30 V、限流和输出开关。
- 函数信号源：正弦、方波、三角波，支持频率、幅值、偏置和占空比。
- 万用表：电压、电流、电阻、电导、通断和二极管档；电阻/二极管测试在检测到外部供电时显示保护提示。
- 双通道示波器：探针地夹、时基、垂直刻度、触发、运行/暂停/单次、游标、峰峰值与 RMS。

仪器带有限输入阻抗和电流负载，使读数会影响电路；所有仪表面板、端子、数字显示、LED/灯泡亮度和波形均来自 `SimulationFrame`。

## 交互与持久化

中央工作台提供选择、连线、删除三种光标模式（快捷键 `V` / `W` / `E`），支持器材放置、吸附、移动、旋转、端子点击或拖动接线、中键平移、滚轮/状态栏缩放和撤销/重做。导线和预览均采用水平/垂直折线，端子附近按器件方向引出；视觉线宽与点击范围独立，细导线仍可轻松点选。视图字段保存画布位置和倍率。

节点不作为器材架中的可添加元件。连线模式点击既有导线会在其上插入节点并拆分导线，保持原有网络与走线；正在接线时点击导线则形成分支连接。点击元件按最近端子连接，点击空白处落点并继续走线，`Esc` 取消当前走线。节点插入和分支作为一次操作撤销。器材使用紧凑的原创 SVG 封装外形，端子位置固定，旋转不倒置名称与参数标签。

仪器和计算收在右侧可选测量栏中，默认不覆盖电路桌；打开后按仪器、实时计算和诊断顺序滚动查看。万用表、电源和示波器采用统一的仪器卡片、读数屏和接线区，不使用 Modal、Drawer 或对话界面；窄屏下切换到器材或测量视图，避免覆盖电路区域。精选实验卡只加载初始电路、目标和公式，不锁定用户操作。

本地保存键为 `next-tutor.electrical-lab.v1:<owner-id>`，保存实验名称、器材、连接、仪器参数和视图；派生波形不持久化，重新打开时重新计算。实验台内支持自动保存、重命名、删除、JSON 导入和 JSON 导出，导入数据须通过版本、数量、尺寸、ID 和连接校验。

## 验收

领域测试覆盖单位解析、文档校验、空工作台、欧姆定律、LED、BJT、RC 瞬态、受保护的带电测阻、JSON 交换、直角走线和节点插入前后的读数一致性；精选实验还包含分压、电导、二极管、灯泡及三极管开关。浏览器验收覆盖直达工作台、无全局助手、光标模式、接线与导线分支、仪表、示波器、精选实验、本地保存、JSON 交换、全屏、窄屏和浅深主题。
