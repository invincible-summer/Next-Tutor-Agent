# 学习编排与笔记系统

> Next Tutor Agent 的学习编排和笔记不是两个独立的效率工具。
>
> 它们共同承担一个更重要的任务：把“这一轮对话学了什么”延伸成“接下来几天、几周应该怎么学”，并把课堂中产生的知识、错误、总结和复习材料沉淀成可长期使用的个人学习资产。

## 1. 为什么需要学习编排

对话式 AI 很容易解决“眼前这个问题”，却很难解决另一个更重要的问题：

**学生下一步应该学什么？**

如果系统只根据当前一句话回答，那么学习会不断被即时问题打断：今天问积分，明天做概率，后天又回到极限，缺少长期目标、知识依赖和复习节奏。

Next Tutor Agent 因此把学习分成两个时间尺度：

- **即时教学**：当前对话里怎么讲、怎么练、怎么纠错；
- **长期编排**：未来几周到几个月如何围绕目标安排学习、练习和复习。

编排层不会替代教学层，而是把教材知识图谱、学习评价和长期目标重新组织成计划。

## 2. 从长期目标倒推学习路径

学生可以建立长期目标，例如：

- 完成某本教材；
- 备考某门课程；
- 在指定日期前掌握一组知识；
- 系统复习某个学科模块。

系统不会只把目标保存成一句文本，而是尝试把目标映射到课程概念和知识范围，再结合教材图谱中的前置关系组织学习顺序。

这使计划能够考虑：

- 哪些知识是目标直接要求的；
- 哪些内容是这些目标的 prerequisite；
- 哪些概念当前已有支持证据；
- 哪些概念仍处于局部、脆弱或冲突状态；
- 哪些任务已经完成，哪些仍未完成。

因此，计划并不只是“把章节平均分成若干天”。它更接近一条基于知识依赖和个人学习状态的学习路径。

## 3. 周计划承担“方向”，今日任务承担“执行”

长期目标通常太大，学生无法直接执行。系统因此把规划拆成两层。

### 周计划

周计划回答：**这一周应该推进哪些知识和任务。**

它负责把长期目标切成可管理的阶段，并保留与具体概念的关系。一个周任务可以继续拆成更明确的子任务，例如：

- 阅读某一节；
- 完成某个概念的讲解学习；
- 做针对性练习；
- 回顾错题；
- 完成一次迁移检测。

### 今日任务

今日任务回答：**今天实际做哪几件事。**

系统会从多个候选来源中选择当天最值得执行的内容，例如：

- 本周尚未完成的学习任务；
- 知识图谱上当前需要推进的概念；
- 已到期的间隔复习；
- 学习评价中仍有待验证或待解决的内容；
- 前一天没有完成、需要继续的任务。

这样，长期计划不会停留在“看起来很完整”的计划表，而会持续转化成具体行动。

## 4. 学习计划与真实学习状态联动

学习编排的关键不是生成一次计划，而是能够根据学习过程继续调整。

如果学生已经在对话和测评中展示出对某个概念的可靠理解，那么后续安排可以减少低价值的重复解释，转向应用、迁移或后续概念。

如果某个概念出现明确错误或证据冲突，系统可以把它重新带回学习任务，而不是因为“计划表上已经划过这一章”就默认学会。

如果学生只是在完整示范后完成任务，也不能简单把它等价成独立掌握；这类帮助条件会限制学习评价，也间接影响后续任务的安排方式。

因此，计划消费的是**学习证据形成的当前状态**，而不是只消费“完成/未完成”的打卡数据。

## 5. 知识图谱让计划有先后逻辑

教材知识图谱在学习编排中的价值尤其明显。

假设学生的目标是学习“定积分应用”，系统不仅可以看到目标节点，还能沿 prerequisite 关系定位其前置概念，例如极限、导数、积分定义或相关基础知识。

如果前置概念中存在明显未解决项，就可以先安排修复，而不是强行推进目标知识。

这让学习计划从“时间排序”升级为“知识依赖排序”。

对于跨册教材，这种能力更有价值：上册中的基础概念可以成为下册内容的前置节点，学习路径不再被文件边界割裂。

## 6. SM-2：把复习节奏交给间隔重复

系统使用 SM-2 管理间隔复习。

SM-2 在这里解决的不是“学生会不会”这个评价问题，而是一个不同的问题：

**什么时候应该把已经学过的内容重新带回来复习。**

评价系统负责保存学生在任务中的真实表现；SM-2 负责维护复习卡片的间隔状态。这两者被明确分开，避免把“很久没复习”误解释成“已经不会”，也避免把“刚做对一次”直接解释成长期保持。

当复习到期时，它会进入今日任务候选池，使旧知识可以在合适时间重新出现。

这种设计把短期学习和长期保持连接起来：学习不是“讲过即结束”，而是存在后续的提取与巩固机会。

## 7. 笔记不是文本编辑器，而是学习内容的沉淀层

Next Tutor Agent 的笔记采用 Markdown 仓库形式，并支持类似 Obsidian 的双链关系。

但项目重点不在于复刻一个笔记软件，而在于让笔记天然连接学习过程。

一篇笔记可以来源于：

- 已发生的对话；
- 教材内容；
- 错题和学习问题；
- 用户自己的整理；
- AI 根据上述材料生成的总结、修正或复习笔记。

因此，笔记不是要求学生在学习结束后手工复制聊天内容，而是可以直接从真实学习上下文中沉淀。

## 8. AI 生成笔记时，来源比“写得漂亮”更重要

系统生成笔记时并不是只输入一个标题让模型自由发挥，而是允许从明确的学习来源组织材料。

例如，学生刚完成一次“电磁感应”学习，可以让系统基于：

- 本次相关对话；
- 当前教材中的定义和公式；
- 错题中暴露出的易混点；

生成一份“电磁感应核心概念 + 易错点 + 温故问题”的笔记。

这样生成出来的笔记既包含课程事实，也包含个人学习过程，而不是一份互联网上随处可见的通用总结。

## 9. 双链让个人笔记逐渐形成第二张知识网络

教材知识图谱表达的是课程的公共结构，而笔记双链表达的是学生自己的知识组织方式。

例如，一篇“动量守恒”笔记可以链接：

- `[[冲量]]`
- `[[完全非弹性碰撞]]`
- `[[质心系]]`
- `[[机械能守恒的适用条件]]`

随着笔记积累，学生会得到一张不同于教材知识图谱的个人知识网络。

两者作用不同：

- **教材图谱**回答课程如何组织；
- **笔记图谱**回答学生如何把自己的知识材料连接起来。

这种双层结构比单纯把所有内容塞进同一个知识图谱更实用，因为它保留了“课程结构”和“个人理解结构”的差异。

## 10. 笔记可以直接进入复习系统

部分笔记模板可以启用温故属性，并接入 SM-2 复习调度。

这使笔记从静态资料变成可重复调用的学习材料。

例如一篇“错因修正笔记”不必只存在仓库里等待学生想起来再看；它可以在间隔复习到期时重新出现在今日学习安排中。

因此形成了：

**对话/练习产生内容 → 笔记沉淀 → 间隔复习 → 再次学习表现 → 更新后续安排。**

## 11. 笔记与学习编排如何互相补充

学习编排解决“做什么”，笔记解决“留下什么”。

如果只有编排，学生完成任务后知识容易散落在聊天记录和题卡中；如果只有笔记，学生又可能拥有大量资料，却不知道下一步该复习哪一篇。

二者结合后：

- 计划可以把“整理某知识点”变成具体任务；
- 对话和教材可以自动沉淀为笔记；
- 笔记可以形成温故卡；
- 温故卡进入 SM-2；
- 到期复习重新进入今日任务；
- 新的学习表现继续影响后续计划。

这让笔记真正进入学习闭环，而不是停留在内容管理层。

## 12. 这一部分的核心创新

### 12.1 编排不是日历，而是知识状态驱动的任务系统

计划同时消费长期目标、教材图谱、当前学习证据、未完成任务和间隔复习，因此它的对象不是“日期”，而是学生的学习进程。

### 12.2 完成任务不等于自动“学会”

编排层负责任务生命周期，评价层负责学习证据。勾选完成不会直接修改学生能力状态。

这避免了很多学习产品中“完成一页 = 掌握一个知识点”的过度推断。

### 12.3 公共课程图谱和个人笔记图谱分工明确

课程知识图谱服务教学顺序和概念身份，笔记双链服务个人知识组织。二者都重要，但不混成一个无法区分来源的网络。

### 12.4 笔记来源于真实学习过程

对话、教材、错题可以直接成为 AI 笔记的素材，使笔记天然包含学生自己的学习痕迹，而不是纯粹生成标准答案式总结。

### 12.5 复习调度把“学过”变成“持续记得”

SM-2 把已经形成的学习材料重新带回计划，使学习系统拥有跨天、跨周的时间维度。

## 13. 一个完整例子

假设学生的长期目标是“六周学完大学物理中的力学部分”。

系统可以先从教材知识图谱定位目标范围及前置概念，形成周计划；今天安排“动量守恒条件 + 两道应用题”。

学生在对话里发现自己一直把动量守恒和机械能守恒混淆，于是系统记录相关学习证据并进行纠偏。学习结束后，可以基于这次对话、教材片段和错题生成一篇“守恒定律适用条件”笔记。

这篇笔记开启温故后进入 SM-2。几天后，它重新出现在今日任务里，学生通过新的独立任务完成一次延迟提取。

新的表现再进入学习评价，后续周计划据此决定继续强化、进入碰撞问题，还是把时间转给其他知识点。

这就是学习编排和笔记在项目中的实际角色：**让一次学习互动可以被保存、被重新调用，并真正影响之后的学习。**
