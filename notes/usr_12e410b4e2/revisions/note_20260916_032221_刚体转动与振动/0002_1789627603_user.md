# 刚体转动与振动

## 转动惯量
$I=\int r^2 dm$；平行轴定理 $I=I_c+md^2$；常用：杆（端点 $\frac13 mL^2$、中点 $\frac1{12}mL^2$）、盘（$\frac12 mR^2$）

## 转动动力学
$M=I\alpha$；转动动能 $\frac12 I\omega^2$；杆下摆 $\theta$ 角：$mg\frac{l}{2}\sin\theta=\frac12\cdot\frac13 ml^2\omega^2$

## 换轴技巧
轴移到距端 $\frac{l}{4}$ 处：$I=\frac1{12}ml^2+m(\frac l4)^2=\frac{7}{48}ml^2$（质心距离变了，下降高度也变！）

## 简谐振动
$x=A\cos(\omega t+\varphi)$ 满足 $\ddot x=-\omega^2 x$；单摆小角度 $T=2\pi\sqrt{l/g}$（大角度失效）；相位法第一次到正最大：相位 $=2\pi$ 不是 $\pi$！
