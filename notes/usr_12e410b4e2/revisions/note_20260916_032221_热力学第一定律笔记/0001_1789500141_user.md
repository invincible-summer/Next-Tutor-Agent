# 热力学第一定律笔记

## 符号约定
$\Delta U=Q+W$：Q 吸热为正；W **对外做功为负**（教材约定），准静态 $W=\int p\,dV$（注意不同教材符号约定相反！）

## 四个过程（理想气体）
| 过程 | 特征 | 要点 |
|---|---|---|
| 等温 | $\Delta U=0$ | $Q=W=\nu RT\ln\frac{V_2}{V_1}$（$pV=C$ 时 $Q=C\ln\frac{V_2}{V_1}$）|
| 等容 | W=0 | $Q=\nu C_V\Delta T$ |
| 等压 | | $W=p\Delta V$，$Q=\nu C_p\Delta T$ |
| 绝热 | Q=0 | $pV^\gamma=$ 常数，$\gamma=C_p/C_V$ |

## 卡诺循环
$\eta_C=1-\frac{T_2}{T_1}$（只依赖两热库温度）；$600\,\mathrm K/300\,\mathrm K$ → 50%。实际热机达不到：卡诺定理的原理性上限（不可逆因素）。
