# 牛顿定律与受力分析

## 三定律核心
1. 惯性定律（惯性系定义）
2. $\vec F=m\vec a$：F 是**合外力**；适用于惯性系、质点（或平动刚体）
3. 作用反作用：等大反向、**作用在不同物体上不能抵消**

## 马拉车悖论
分别对车、马写方程：车受拉力 > 车所受阻力才加速；「等大反向」的力不在同一物体上，不进同一方程。

## 弹簧连接体
光滑面恒力 F 拉二体：先整体 $a=F/(m_1+m_2)$，再隔离求弹簧张力。

## 楔形块压力
无摩擦滑块对楔的压力竖直分量 $mg\cos^2\theta$（两个不同的 $\cos\theta$ 相乘）。
