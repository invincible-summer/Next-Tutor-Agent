# 微分中值定理

## 两大定理
- **罗尔**：$[a,b]$ 连续、$(a,b)$ 可导、$f(a)=f(b)$ $\Rightarrow$ 存在 $\xi$ 使 $f'(\xi)=0$
- **拉格朗日**：$f'(\xi)=\frac{f(b)-f(a)}{b-a}$（罗尔是其 $f(a)=f(b)$ 特例）

## 几何意义
割线斜率 = 某点切线斜率：曲线总有一处「跟上」平均变化率。

## 易错
端点代入顺序：分母必须是 $b-a$，分子 $f(b)-f(a)$（我曾把 $\frac{8-2}{3}$ 当成斜率，正确是 $\frac{8-2}{3-1}=3$）。
