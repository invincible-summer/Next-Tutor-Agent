# 守恒定律笔记（动量·角动量·能量）

## 动量守恒
条件：合外力为零（或某方向分量为零）；碰撞瞬间内力≫外力可近似。
- 完全非弹性碰撞：共速，动能损失最大（一动一静损失 $\frac12\mu v_0^2$ 量级）
- 弹性碰撞：动能不损失

## 角动量守恒
$\vec L=I\omega$；对轴合外力矩为零时守恒。
- 子弹打杆：$mvl=(\frac13 Ml^2+ml^2)\omega$（碰前杆静止、位置不变）
- 花样滑冰收臂：$I$ 减小 → $\omega$ 增大，动能**增加**（肌肉做功）

## 机械能守恒
只有保守内力做功时 $E_k+E_p$ 不变。重力势能零点任选（势能差才物理）；卫星椭圆轨道：角动量守恒给 $v_2=v_1 r_1/r_2$，机械能守恒给能量关系。
