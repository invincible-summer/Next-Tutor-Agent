# 定积分与可积性

## 定义（分割-取点-求和-取极限）
$\int_a^b f = \lim_{\lambda\to0}\sum f(\xi_i)\Delta x_i$，$\lambda=\max\Delta x_i$（不是 $n\to\infty$！）

## 可积的充分条件（教材层次）
- 闭区间连续 → 可积
- 闭区间单调 → 可积
- 有界 + 有限个间断点 → 可积

## 运算封闭性
$f$ 可积 ⇒ $|f|$、$kf$ 可积；$f$ 可积 + $\varphi$ 连续 ⇒ $\varphi(f)$ 可积（外层连续是关键，两个「连续」不要记反）。

二重积分的曲线坐标推广（$\xi=y^2/x$ 型、雅可比 $1/3$）是同一套换元思想，见 [[积分换元法]]。返回 [[微积分学习路线图]]。
