# 级数敛散判别手册

## 第零步（最先做！）
检验通项：$a_n\not\to0$ ⇒ 发散。陷阱题（如 $(\frac{2n}{2n-1})^p$，$a_n\to1$）一步毙命。

## 正项级数判别顺序
1. **比较判别法**：与 $p$-级数、几何级数比
2. **比值（达朗贝尔）**：含 $n!$、$a^n$ 优先；$\rho<1$ 收敛
3. **根值（柯西-阿达马）**：$(\ )^n$ 结构优先；幂级数 $R=1/\limsup\sqrt[n]{|a_n|}$
4. **积分判别法**：$\frac{1}{n\ln n}$ 型，与 $\int f$ 同敛散（$p$-级数与 $\int x^{-p}$ 的联系）
5. **拉阿伯**：$\lim n(\frac{a_n}{a_{n+1}}-1)=R$，$R>1$ 收敛、$R<1$ 发散、$R=1$ 失效

## 端点必单独讨论
$\sum\frac{(2n)!}{(n!)^2}x^n$：$R=\frac14$，端点通项 $\sim\frac{1}{\sqrt{\pi n}}$ 不趋 0 → 发散。
